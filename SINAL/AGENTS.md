# Orientações de manutenção

Esta cópia é independente do Lovable. Preserve React 19, React Three Fiber 9 e Drei 10, além dos componentes originais do Teddy e de um único TeddyProvider global. Mantenha TypeScript estrito. Use npm ci, npm run check e npm run build. Preserve a composição desktop e confira telas estreitas ao alterar a interface. Não publique sem solicitação do responsável pelo projeto.
